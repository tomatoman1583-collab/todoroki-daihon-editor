# 指示の出し方ガイド（発注側＝マサトさん向け）

クライアント要望どおりの台本を一発で出すには、依頼のとき次の材料をくれると精度が上がる。
「面白く書いて」だけだと、AIは知っている事実を並べて言い換えるだけになりやすい（＝今回クライアントが指摘した状態）。
**AIに足りないのは文章力ではなく「その車の一次情報・背景」**。そこを渡すのがコツ。

## 台本を新規で頼むとき、あると強い情報

1. **車名と、狙ってほしい冒頭フック**（なければ「フックはお任せ」でOK）
2. **メーカーの狙い**（誰に売ろうとした車か。分かる範囲で）
3. **競合車の具体名**（何と比べられて負けたか）
4. **効いた／効かなかったスペックや設計**（数値と、それが評価にどう響いたか）
5. **消えた最大の理由（あなたの見立て）**（無ければAIが仮説を出すので後で選んでもらう）
6. **尺の目安**（何分 or だいたいの行数）
7. **佃さんの参考台本**（初回に数本。以後はスキルに蓄積されるので毎回は不要）

> 3〜5が分からない車は「ここは調べて仮説を出して」と言ってくれれば、AI側で候補を出して確認する。

## コピペで使える依頼テンプレ

```
轟き台本スキルで、次の車の台本を書いて。

車名：〇〇
狙い（誰に売ろうとした車か）：
競合（比べられて負けた相手）：
効いた/裏目に出たスペック・設計：
消えた最大の理由（自分の見立て）：※不明ならAIに仮説出しを依頼
冒頭フックの希望：※なければお任せ
尺：約〇分 / 約〇行
その他：
```

## 修正を頼むとき

- 「L〇〇を直して」のように**行番号**で範囲を指定してくれると速い。
- 「事実の羅列っぽいから深掘りして」「比喩が多い」「締めが前の車と被ってる」など、
  **どのルールに引っかかっているか**を一言添えると、狙った方向に直せる。

## 覚えておくと良いこと

- このスキル（`.claude/skills/todoroki-daihon/`）が入っているので、
  **「轟き台本スキルで」と言うだけ**でクライアント要望（5要素・比喩抑制・構成/締めの多様性・26字/句点なし）が自動で効く。
- 毎回クライアント要望を説明し直す必要はない。要望が変わったときだけ、スキルを更新すればよい。
- 佃さんの新しい参考台本をもらうたびに `tsukuda-style.md` を育てると、口調の再現度が上がる。
