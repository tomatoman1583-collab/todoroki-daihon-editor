# クライアント改善例（原文ベース）

クライアントのPDF修正依頼に載っていた「改善例」をそのまま参照用に保存。
**書き方の手本**として使う。ただし、ここでは分析の中身を示すため散文で書いてある。
実際の納品では `format.md` の26字・句点なしフォーマットに変換すること。

## 例① キザシ（狙いと販売網のズレ）

事実の羅列で終わっていた原文：「300万円クラスだった」「試乗車が少なかった」「一般販売は不振だった」。

改善の要点：
- 最大の誤算は完成度ではなく「スズキで300万円のセダンを売ろうとしたこと」。
- スズキ販売店の客は軽・コンパクト目当て → 300万円セダンは検討されにくい。
- 同価格帯を狙う客はクラウン・マークX・アコードを選ぶ（知名度）。
- 既存スズキユーザーには高すぎ、高級セダン層にはブランド力不足。
- 「誰に売る車なのか」が国内で不明確だった、が本質。試乗車の少なさはその次。

## 例② マークXジオ（「分かりづらい」を具体化）

原文：「コンセプトが分かりづらい」「3列目は緊急用」「一代限り」。
→ **なぜ**分かりづらかったのかを具体化する。

- セダンの上質さとミニバンの広さの両立を狙った。
- ファミリー層が欲しかったのはスライドドア・広い3列目・積みやすさ（分かりやすい便利さ）。
- マークXの名に惹かれる層が欲しかったのは後輪駆動の走り・高級セダンらしさ。
- 中間を狙った結果、ミニバンとしては実用性不足、セダンとしてはマークXらしさ希薄。
- 長所は多いが、どの客層にも「これでなければならない理由」が弱かった。

## 例③ ホンダ・ジェイド（狙いと需要のズレ）

原文：「全高が低い」「ヒンジドア」「3列目が狭い」「売れなかった」。
→ ホンダの狙いと市場の需要がどうズレたかを説明する。

- 狙いは「低くて走りの良い3列シート車」。全高1530mm、ヒンジドア、美しさと低重心を優先。
- 当時のミニバン客が重視したのは走りより乗せ降ろしやすさ・3列目の広さ。
- ミニバンとして見ると便利さ不足、ステーションワゴンとして見ると3列目が価格・重量の負担。
- 「低くて美しい3列シート車」と「家族が便利に使えるミニバン」が噛み合わなかった。

## 例④ ホンダ・グレイス（市場そのものの消失）

原文：「燃費が良い」「後席が広い」「セダン人気低下」「売れなかった」。
→「セダン人気が低下したから」だけでは浅い。**どの車に客を奪われたか**まで。

- 燃費・後席の広さ・取り回しを備えた真面目な小型セダン。
- 同価格帯に積みやすいフィット・ヴェゼルが存在。
- 実用重視層はハッチ/SUVへ、高級感を求める層にはグレイスは小さく地味。
- 実用車ではフィットに負け、趣味性・存在感ではSUVに負けた。
- グレイスが悪いのではなく、セダンが購入理由になりにくい時代へ変わった。

# 比喩の扱い（避けたい例／改善例）

**避けたい例（比喩で終わって内容が軽い）**
> 売れない歌手が芸名を変えたのに、客席の顔ぶれは変わらない暴挙です。

**改善例（比喩→即・分析へ戻す）**
> 売れない歌手が芸名と衣装を変えたような大胆な路線変更でした。
> しかしクロスオーバー7へ改名しても、ヒンジドアの3列シート車という基本的な性格は変わっていません。
> スライドドアを求めるファミリー層には依然選ばれにくく、
> SUVを求める層には車高や外観の迫力が物足りない、という課題が残りました。

比喩は1台0〜1回。書いたら必ず「それが何を意味するか」を具体語で説明して着地させる。

# 冒頭フックと締めの対応表（多様性の担保）

| 車 | 冒頭フック（例） | 締め（消えた最大の理由） |
|---|---|---|
| キザシ | スズキ史上最高級の300万円セダン | 商品力ではなく、ブランドと販売網の限界に敗れた車 |
| ブレイド | 小型ハッチバックに280馬力のV6 | 売るためではなく、当時のトヨタの余裕と遊び心から生まれた車 |
| ギャランフォルティス | ランエボXと基本骨格を共有 | （車固有の理由を1つ立てる） |
| クロスオーバー7 | 改名してSUV化した延命モデル | 改名しても基本性格が変わらず、どの層にも刺さらなかった車 |
| マークXジオ | セダン×ミニバンの両立に挑んだ | 詰め込みすぎて、誰のための車か分からなくなった車 |
| ジェイド | 全高1530mmの低い3列シート車 | メーカーの美学と、ファミリー層の現実が噛み合わなかった車 |
| グレイス | 真面目さで固めた小型セダン | 欠点ではなく、それを求める市場そのものが消えた車 |

冒頭と締めは車ごとに必ず変える。同じ入り・同じ締めを2台で使わない。
