# 佃さんスタイル分析（実物4本から抽出）

分析元：佃さん執筆の実台本4本
（宣戦布告6選／軽自動車爆死13選＝L266／歴史に残る失敗作10選＝L232／日本車最も失敗TOP10＝L280）
※台本原文はリポジトリに置かない（公開リポジトリのため）。ここには特徴の要約のみ。

---

## 1. 全体構成の型

1. **挨拶＋小ネタ**：「みなさんどうも轟です」＋自虐や近況の一言ボケ
   （例の型：「最近自炊を始めた轟です 包丁が全く使えないので〜」「駄作の轟が、駄作の自動車を解説します」）
2. **タイトルコール**：「さあ今回は、【◯◯】をお届けいたします」
3. **テーマ論（重要）**：1台目に入る前に、そのテーマの「定義・視点」を一段立てる
   - 例の型：「本当に語るべき失敗とは、単に売れなかったクルマではない」
     「失敗とは出来の悪さではなく“ズレ”である」
   - この一本の「論」が全車を貫き、締めで回収される
4. **各車パート**（詳細は§2）
5. **ラストの一台**：「今宵のラスボス」として一番の変化球・大ネタを置く
6. **締め**：テーマ論の回収 → 視聴者への問いかけ（コメント誘導）→ 登録・高評価 →
   「今回も最後までご視聴いただきありがとうございました また次回〜」

## 2. 各車パートの型

順序は固定でなく変奏するが、要素はほぼ毎回この構成：

1. **ブリッジ**：「さて◯◯を見てきたところで、続いては〜」と前の車から橋を架ける
2. **フック一言**：「〜してしまった一台で、その名も◯◯です」
   ＝その車の失敗を一行で予告してから車名を出す（車名が先ではない）
3. **時代背景・市場の空気**：「2000年代初頭、軽自動車市場では“◯◯”がトレンドでした」
4. **メーカーの狙い**：何を目指して投入したか
5. **現実とのズレ**：「しかし問題は〜」「しかし現実は厳しく〜」で転調
6. **競合の具体名**：ラパン・ワゴンR・セルシオ・フィット等、必ず名指しで対比
7. **結果**：「結果として販売は伸び悩み、気付けば静かに終了・・・」
8. **現在からの再評価**：「ただ現在見ると、逆に魅力的」「時代が追いつかなかった」
   ＝車ディスで終わらせず、必ず一度愛でる（クライアントの意向とも一致）
9. **一行の結論**：車固有の敗因を言い切る →「そんな一台だったと言えるでしょう」

## 3. 分析の切れ味（一行サマリの技術）

佃さんの真骨頂。**敗因を対句・逆説で一行に圧縮する**：

- 「車としては成功、ブランドとしては失敗」
- 「足し算を続けた結果、引き算ができなくなったクルマ」
- 「面白い車だけど、購入動機には変換できない車」
- 「駄作と呼ばれた理由は性能ではなく、座る前に考えさせてしまったこと」
- 「それ◯◯でよくない？問題」（安価な代替車に食われる構図の定番表現）
- 「失敗とは出来の悪さではなく“ズレ”」

→ 執筆時は各車に必ずこの「一行サマリ」を作ってから本文を書くと佃さんに寄る。

## 4. 口調・言い回し

- **です・ます敬体**ベース＋**体言止め**を混ぜてリズムを作る
- 一人称は「轟」。**自虐キャラ**（例の型：「尊厳・・・轟にはひとかけらもない、あの尊厳です」）
  ※自虐は轟自身に向く。車や客をバカにする方向には使わない
- 視聴者のツッコミを先回り：「『ついに頭がおかしくなったのか？』と声が聞こえてきそうですが」
- 「・・・」で余韻・言いよどみを表現（多用してよい）
- 修辞疑問で転換：「結果はどうなったのか？」「一体なぜか？」
- 常用語彙：今宵／ラスボス／お届けいたします／気付けば／そんな中／一方／つまり／
  結果として／とはいえ現在見ると／〜と言えるでしょう／〜のかもしれません
- 感嘆符・疑問符は使うが1台に1〜2回まで

## 5. 比喩の使い方

- **1台につき0〜2回、1行完結**、直後に必ず分析へ戻る（比喩で段落を終えない）
- 例の型：「白米の上にフレンチのソースだけ全力でかけた感じ」
  「スーツは完璧なのに、靴だけやたら主張が強い人」
  「高級車という椅子取りゲームの中で、最後に入ってきて椅子が無かった」
- 人間に例える比喩も使うが、短く・軽く・すぐ着地。連発しない
- ※クライアント指示（1台0〜1回）が優先。佃さんが2回の箇所があっても納品は0〜1回に抑える

## 6. 数値・事実の扱い

- スペックの羅列はしない。数値は「ズレ」を示す道具としてだけ出す
  （例の型：Eタイプ約6000ドル vs 240Z約3500ドル「ほぼ半額」→ 宣戦布告の証拠として）
- 発売年は「時代の空気」とセットで語る（「1999年当時のホンダはオデッセイが大ヒットしており〜」）

## 7. 納品フォーマット（実物から確認済み）

- **1行26字以内**（実測：最大26字、平均17〜19字。26字ぴったりまで使ってよい）
- **句点「。」ゼロ**。読点「、」「・・・」「！」「？」は使用可
- **1つの意味単位＝1つのNo.**（001, 002, ...）。長い場合は **-01 / -02 の2行に分割**（3行分割はしない）
- 意味単位の間は**空行**
- 車名はセリフとは別の1行（見出し行）として立てる
- 冒頭挨拶と結びの定型（登録・高評価→視聴御礼→次回予告）はほぼ毎回同じでよい

## 8. 執筆時セルフチェック（佃寄せ）

- [ ] 冒頭に轟の自虐 or 小ネタ一言があるか
- [ ] 1台目の前に「テーマ論」を立てたか／締めで回収したか
- [ ] 各車がブリッジ→フック一言→背景→狙い→ズレ→競合名→結果→再評価→一行結論の要素を持つか
- [ ] 各車に「一行サマリ」（対句・逆説の敗因圧縮）があるか
- [ ] 車を一度は愛でたか（再評価・フォロー）
- [ ] 「そんな一台だったと言えるでしょう」を連発しすぎていないか（言い換えを混ぜる）
- [ ] ラスボス（最後の一台）が一番の変化球になっているか
