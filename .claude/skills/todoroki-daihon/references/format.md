# 納品フォーマット仕様と検証手順

台本は `index.html`（轟 台本エディタ）で読み込まれ、機械的にチェックされる。
エディタの実装（`render()`）が見ているのは次のとおり。

## ルール

| ルール | エディタの挙動 | 対応 |
|---|---|---|
| 1行26字以内 | `len(t) > 26` の行を**赤**表示・「26字超過」カウント | 意味の切れ目で改行し、各行26字以内に収める |
| 句点「。」禁止 | `。` を含む行を**黄**表示・「句点」カウント | 文末の句点を打たない。区切りは改行で表す |
| 1行＝1読み上げ | 行をクリックするとその行から読み上げ | 1行に1つの意味・ひと息で読める長さ |
| 空行でブロック区切り | 空行は `blank` として表示 | 話題のまとまりごとに空行を入れる |

補足：
- 文字数カウントは `[...s.trim()].length`（コードポイント単位）。全角も半角も1文字＝1。前後の空白は無視される。
- 読点「、」は制限なし。長い行は「、」の位置で改行するのが自然。
- 「26字」はあくまで上限。読みやすさ優先で、多くの行はもっと短くてよい。

## 書き方のコツ

- 一文が長くなったら、主語・条件・結論で改行して複数行に割る。
- 数値（300万円、1530mm、280馬力など）は行頭 or 行末に置くと読み上げが安定する。
- 体言止め・言い切りを活用して句点なしでもリズムを作る。

## 納品前の機械チェック手順

1. 台本テキストを `index.html` をブラウザで開いて貼り付ける（またはファイルを「台本を開く」で読み込む）。
2. 上部の指標を確認する：
   - **26字超過 = 0**（赤い行がない）
   - **句点 = 0**（黄色い行がない）
3. 赤・黄が残っていれば全て解消してから納品する。

### コマンドラインで素早く自己チェックしたい場合

エディタと同じ条件で、超過行と句点行だけ洗い出す簡易スクリプト：

```bash
python3 - "$FILE" <<'PY'
import sys
for i, line in enumerate(open(sys.argv[1], encoding='utf-8'), 1):
    t = line.strip()
    n = len(t)                       # コードポイント数＝エディタのlen()と同じ
    flags = []
    if n > 26: flags.append(f'26字超過({n})')
    if '。' in t: flags.append('句点')
    if flags and t:
        print(f'L{i}: {" / ".join(flags)} : {t}')
PY
```

出力が空なら機械チェックはパス。
