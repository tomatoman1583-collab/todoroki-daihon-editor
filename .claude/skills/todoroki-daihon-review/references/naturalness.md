# 自然さ・AIっぽさ レビュー（通し読み代行）

ユーザーの代わりに台本を通しで読み、「AIが書いた感じ」「不自然さ」「単調さ」を消して、
そのまま納品できる質にする。機械スキャン（数える）と通し読み（判断する）の両輪で行う。

## 手順

1. **機械スキャン**：台本全文で下記の「AIっぽさ指標」を数える（数えるスクリプトは末尾）。
   閾値を超えた語・構文は、クラスターしている箇所を優先して言い換える。
2. **通し読み**：数字に出ない不自然さ（温度のなさ・説明の重複・オチの弱さ・文の据わりの悪さ）を、
   1台ずつ声に出す気持ちで読んで直す。
3. **事実の分離**：読みながら、断定できない事実に印をつけ、別途「確認推奨リスト」にまとめる。
4. **再検証**：直したら26字/句点・ですます体言比率（`todoroki-daihon/references/`）を再チェック。
   直す過程でこれらを壊していないか必ず確認する。

## AIっぽさ指標（機械で数える）

数が多い＝即NGではない。**同じ手が繰り返されて“型”に見える**のが問題。目安の閾値：

| 指標 | 何がAIっぽいか | 目安 | 対処 |
|---|---|---|---|
| 冒頭の同型テンプレ | 各車が「◯年に登場した初代◯◯は」等で揃う | 同型は**2台まで** | 語順を変える／体言止めにする／別の事実から入る |
| 「それでも〜」で始まる締め | 全車が同じ逆接で美点に着地 | 全体**5回まで・1台1回まで** | むしろ／とはいえ／ところが／ただ 等に散らす |
| 「〜という」 | 名詞化の多用はAIの手癖 | 近接で3連発しない | 動詞で言い切る／削る |
| 質感の使い回し | 「堂々たる」「まさに」「その名も」等の決まり文句 | 同一語**2回まで** | 別語に置換（1回だけ残すのは可） |
| 文末「でしょう」「のです」 | 断定を避ける優等生口調の連発 | 近接で続けない | 言い切る／体言止め |
| 「〜ではなく〜」 | 対比構文の反復 | **テーマの核なら保持可**（下記) | 単なる飾りの対比だけ削る |

**重要な判断**：反復でも「主張そのもの」なら残す。
例：値上げ動画の「高くなったのではなく買い手が変わった」は「〜ではなく」が主張の核なので、
回数が多くても消さない。機械的に潰さず、**その反復が意味を運んでいるか**を読んで決める。

## 通し読みで見る（数字に出ない不自然さ）

- **説明の重複**：同じことを言い換えて2回言っていないか（片方を削る）。
- **温度のなさ**：事実の羅列で終わって轟の視点・感情がない段落はないか。
- **オチの弱さ**：各車の締めの一行が、対句・逆説で効いているか（`tsukuda-style.md`の一行サマリ）。
- **文の据わり**：声に出して読んで、息継ぎ・リズムが不自然な行を直す。
- **不自然な丁寧さ／優等生さ**：無難すぎて轟の毒・自虐が消えていないか。
- **禁止表現**：「ということです」等（`todoroki-daihon/references/tsukuda-style.md`）が混じっていないか。

## 事実の確認推奨リスト（ユーザーに渡す形）

読みながら、次に当たるものへ印をつけ、台本本体とは別に箇条書きで出す：
- 具体的な数値（価格・馬力・年式・台数）で、うろ覚え・世代で変わりうるもの。
- 最近／未来のモデル情報（新型の発売・価格・受注状況、復刻サービス等）。
- 因果の主張（「〜だから相場が上がった」等、断定しづらい分析）。※本文は「〜と言われます」等で和らげておく。

各項目：`該当No. / 主張 / 何が不確かか`。ユーザーはこの数行だけ確認すればよい。

## 機械スキャンのスクリプト

```bash
python3 - "$TXT" <<'PY'
import sys, re, collections
lines=[l.split('\t',1)[1].strip() if '\t' in l else l.strip() for l in open(sys.argv[1],encoding='utf-8') if l.strip()]
full=''.join(lines)
for t in ['という','それでも','ではなく','でしょう','のです','堂々たる','まさに','その名も','気づけば']:
    n=full.count(t)
    if n>=3: print(f'{t}: {n}回')
print('冒頭テンプレ(年に登場した初代):', sum(1 for l in lines if '年に登場した初代' in l))
# 近接反復（4〜8字の語が3回以上）
c=collections.Counter(m for l in lines for m in re.findall(r'[ぁ-んァ-ヶ一-龠]{4,8}',l))
for p,n in c.most_common():
    if n>=3 and p not in ('というより',): print(f'反復: {p} {n}回')
PY
```
